一、專案簡介與系統定位
--------------------------------------------------------------------------------
Run Tracker 是一款基於網頁技術 (Web App / PWA 導向) 開發的專業跑步數據追蹤與分析系統。
具備零安裝、即開即用、隱私安全 (所有數據預設存放於使用者本地瀏覽器 LocalStorage) 之特色。
視覺採用 Dark Neon (暗黑霓虹) 與 Glassmorphism (玻璃擬物) 現代簡潔風格，專為智慧型手機與行動裝置體驗打造。

--------------------------------------------------------------------------------
二、技術棧與依賴套件 (Technology Stack)
--------------------------------------------------------------------------------
1. 核心前端框架：React v18.2.0 (搭配 Vite v5.4.21 建置工具)
2. 語言：JavaScript (ES6+ JSX)
3. UI 圖示庫：Lucide React v0.344.0
4. 視覺與樣式：Vanilla CSS3 (自訂設計系統、CSS 變數、網格與彈性佈局)
5. 瀏覽器原生地理定位 API：HTML5 Geolocation API (navigator.geolocation)
6. 語音合成 API：Web Speech API (window.speechSynthesis / SpeechSynthesisUtterance)
7. 原生分享與剪貼簿 API：Web Share API (navigator.share), Clipboard API (navigator.clipboard)
8. QR Code 分享：QRServer 向量技術 API 結合自訂離線 SVG/Canvas 渲染機制
9. 自動化部署腳本：Node.js 專屬構建部署檔 (`do_build.mjs`, `do_deploy.mjs`, gh-pages)

三、主要模組與頁面規格 (Module & Screen Specifications)
--------------------------------------------------------------------------------

【1. 全域導覽與版面 (Header & 5-Tab Navbar)】
  - 頂部列 (Header)：展示 App 品牌標誌與當前系統模擬狀態。
  - 底部分頁欄 (Navbar)：提供 5 個標準選單切換（跑步、統計、紀錄、設定、說明），具備動態縮放與 Neon Green 光暈標示。

【2. 跑步追蹤模組 (RunScreen.jsx)】
  - GPS 定位追蹤：自動讀取經緯度、計算海龍公式 (Haversine Formula) 計算移動距離。
  - 模擬器模式 (GPS Simulator)：內建信義區/大安森林公園實測跑線模擬器，方便測試與示範。
  - 即時儀表板：
    * 移動總距離 (km, 精確至小數點後兩位)
    * 總運動時間 (hh:mm:ss)
    * 當前與平均配速 (min/km)
    * 卡路里消耗估算 (kcal, 根據體重與 METs 算式)
  - 語音提示系統：每完成 1 公里自動呼叫 Web Speech API 進行中文語音提醒報數。
  - 運動控制：支援「開始/恢復」、「暫停」、「完成並儲存」三大按鈕狀態機控制。

【3. 數據統計與高階分析 (AnalyticsScreen.jsx)】
  - 總數據統計：總累積跑量、總跑步次數、總運動時數、平均配速。
  - 個人最佳紀錄 (Personal Records, PR)：
    * 1K 最快分段 (具備漂移過濾算式，排除 GPS 跳躍異常點)
    * 5K 最快紀錄
    * 10K 最快紀錄
  - 月度跑量柱狀趨勢圖 (Bar Chart)。
  - 配速分區分析與跑量比例圖。

【4. 歷史紀錄模組 (HistoryScreen.jsx)】
  - 訓練清單展示：按時間倒序排列歷史跑步紀錄。
  - 紀錄詳情：單次距離、耗時、平均配速、消耗熱量與完成時間戳記。
  - 單筆紀錄刪除與全紀錄清空功能。

【5. 系統設定與備份 (SettingsScreen.jsx)】
  - 語音回報開關與音量調節滑桿。
  - 個人參數設定：目標里程、跑者體重 (以精確計算卡路里)。
  - GPS 模擬器模式切換開關。
  - 資料備份與還原：一鍵導出 JSON 紀錄檔案、導入 JSON 歷史數據。

【6. 使用說明與 QR Code 分享 (HelpScreen.jsx & QRCodeCard.jsx)】
  - 動態 QR Code 生成：自動捕捉目前網址，支援相機掃描。
  - 分享互動卡片：具備「一鍵複製網址 (帶 Toast 提示)」與「手機原生分享 (Web Share API)」。
  - 圖文教學卡片：
    * 🏃‍♂️ 快速上手指南
    * 🔊 語音提醒播報說明
    * 🔋 GPS 定位與手機背景省電避坑建議 (iOS Safari / Android Chrome)
    * 📊 數據紀錄與備份管理
    * 📱 將 App 加入手機主畫面 (PWA) 教學

四、資料結構規格 (Data Schema)
--------------------------------------------------------------------------------

【單筆跑步紀錄 (Run Record Object)】
{
  "id": "run_1723456789000",
  "date": "2026-08-12T10:00:00.000Z",
  "distance": 5.25,          // 單位：公里 (km)
  "duration": 1820,          // 單位：秒 (seconds)
  "avgPace": "5'46\"",       // 平均配速
  "calories": 368,           // 單位：大卡 (kcal)
  "path": [                  // GPS 經緯度軌跡陣列
    { "lat": 25.0330, "lng": 121.5654, "timestamp": 1723456789000 }
  ]
}

【使用者設定檔 (Settings Object stored in LocalStorage)】
{
  "voiceEnabled": true,
  "voiceVolume": 1.0,
  "weightKg": 65,
  "targetDistanceKm": 5.0,
  "simulatorMode": false
}

--------------------------------------------------------------------------------
五、構建與自動化部署指令 (Build & Deployment)
--------------------------------------------------------------------------------
1. 本地開發偵測：`npm run dev:local`
2. 正式版打包：`node do_build.mjs` (編譯輸出至 `dist/` 目錄)
3. 自動發布至 GitHub Pages：`node do_deploy.mjs` (自動發布至 `gh-pages` 分支)
