# 自動提交並 Push 到 GitHub 規則 (Auto-push to GitHub Rule)

- **核心指令**：除非使用者有特別交代或明確要求暫緩，每當完成程式碼修改與驗證後，請一律自動 commit 並 `push` 到 GitHub 遠端倉庫（若專案有 GitHub Pages 部署腳本，亦一併自動執行部署）。
- **Execution Rule**: Unless explicitly instructed otherwise by the user, after completing code edits and verification, always automatically commit and `push` the changes to GitHub remote repository (and trigger deployment script if applicable).
